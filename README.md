# Teledata One — الدليل الذكي وتطبيق الويب التفاعلي
### لوحة التحكم في إنذار الحريق (Fire Alarm Control Panel)
**الإصدار 1.3.7 — تعليمات أصلية — نوفمبر 2019**  
**المصنع: Teledata s.r.l. — ميلانو، إيطاليا**

---

تطبيق ويب احترافي مكتفٍ بذاته يعمل **100% بدون إنترنت (Offline)** كملف HTML مستقل، ومجهّز للتحويل المباشر إلى تطبيق أندرويد APK عبر **Capacitor** أو **PWA Builder**.

تم استخراج وبناء هذا الدليل من النسخة العربية المعتمدة المكونة من 95 صفحة، مع الحفاظ على أسماء الأزرار والقوائم والرسائل والمصطلحات التقنية باللغة الإنجليزية كما تظهر على شاشة اللوحة، وشرحها المفصل بالعربية.

---

## 🌟 مميزات التطبيق

1. **ملف واحد متكامل ومكتفٍ بذاته (`index.html`):**
   - لا يتطلب أي خادم (Server) أو اتصال بالإنترنت.
   - يتضمن جميع الصور والمخططات التوضيحية الـ 46 مضمّنة بتقنية WebP فائقة الدقة.
   - يدعم الوضع الليلي والنهاري ومحاذاة RTL كاملة.

2. **محرك بحث فوري ذكي ثنائي اللغة (Bilingual Omnisearch):**
   - معالجة النصوص العربية وتجاوز التشكيل وتوحيد الهمزات والألف والياء والتاء المربوطة.
   - بحث متوازٍ باللغتين العربية والإنجليزية (مثال: كتابة `fault` أو `عطل` تُعطي نفس النتائج الدقيقة).
   - بحث فوري في الأكواد التقنية والموصلات (مثل `J4`, `AL 7`, `T1`, `ONEMODULE301`, `22222`).
   - تمييز النص المطابق بصرياً والقفز مباشرة للفقرة مع نبض ضوئي مميز (`Pulse highlight`).

3. **عارض تفاعلي للصور والمخططات (Interactive Lightbox):**
   - يدعم التكبير والتصغير والتحريك بالسحب واللمس المتعدد (Pinch-to-zoom) للتحكم بالمخططات الدقيقة مثل `TD571/E` و `TD574/E`.

4. **قسم "الأعطال والرسائل والأكواد" (Faults & Diagnostic Messages):**
   - جدول شامل ومصنف لمؤشرات الـ LED، ورسائل الشاشة، وحالات الأعطال، وأطراف الموصلات مع زر مباشر "اذهب للصفحة في الدليل الكامل".

5. **قسم "دليل الصيانة الدوري" (Maintenance & Inspection Log):**
   - يجمع جميع إجراءات الصيانة واختبار المشي (Walk Test) وتشخيص نظافة الكواشف (Diagnostics).
   - جدول فحص وتفتيش دوري جاهز للطباعة المباشرة بصيغة A4 مع خانات للتوقيع والملاحظات.

6. **حفظ موضع القراءة والإشارات المرجعية محلياً:**
   - حفظ تلقائي لآخر فصل وقسم تمت قراءته في `localStorage` مع شريط استئناف القراءة.
   - نظام إشارات مرجعية (Bookmarks) لحفظ الصفحات والأقسام المهمة.

## 📱 التحويل إلى تطبيق أندرويد (APK)

التطبيق مجهّز مسبقاً بملفات الإعداد:
- `manifest.json`
- `sw.js`
- `capacitor.config.json`
- `package.json`

### الطريقة الأولى: عبر PWA Builder (الأسهل بدون تثبيت أدوات)
1. افتح موقع [pwabuilder.com](https://www.pwabuilder.com/).
2. أدخل رابط استضافة المشروع (عبر GitHub Pages مثلاً).
3. اضغط **Package for Android** لتحميل ملف APK جاهز للتثبيت على الهواتف.

### الطريقة الثانية: عبر Capacitor
```bash
# تثبيت الحزم المطلوبة
npm install

# إضافة منصة الأندرويد
npx cap add android

# مزامنة الملفات
npx cap sync

# فتح المشروع في أندرويد ستوديو وبناء الـ APK
npx cap open android
```
